برنامج مواقيت الصلاه - Fluent Prayer Times (WinUI 3)
المطور: محمد النجار - Vibe coding with Instinct.AI

المتطلبات: Windows App Runtime 1.6 (x64) - تثبيت مرة واحدة:
https://aka.ms/windowsappsdk/1.6/latest/windowsappruntimeinstall-x64.exe

التشغيل: فك الضغط ثم شغل FluentPrayerTimes.exe. هتظهر أيقونة المأذنة في الـ tray (ممكن تحت السهم ^).

- كليك على الأيقونة: تفتح/تقفل النافذة. كليك يمين: فتح / الإعدادات / خروج.
- Hover على الأيقونة: "باقي على صلاة <الاسم>: <الوقت المتبقي>".
- الإعدادات: المظهر (Mica Alt / Mica / Acrylic - فاتح / غامق) - المدينة - بحث - تحديد الموقع - التوقيت الصيفي - التشغيل مع ويندوز.
- الإعدادات والمواقيت في %APPDATA%\FluentPrayerTimes فتشتغل أوفلاين.
- البرنامج مش موقّع: لو ظهر SmartScreen اختار More info ثم Run anyway.
