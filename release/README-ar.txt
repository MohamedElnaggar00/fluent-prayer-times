برنامج مواقيت الصلاة - Fluent Prayer Times (WinUI 3)
المطوّر: محمد النجار - brought to you by app.instinct AI

المتطلبات: Windows App Runtime 1.6 (x64) - يُثبَّت مرة واحدة:
https://aka.ms/windowsappsdk/1.6/latest/windowsappruntimeinstall-x64.exe

التشغيل: فُكّ الضغط ثم شغّل FluentPrayerTimes.exe. ستظهر أيقونة المئذنة في منطقة الإشعارات (قد تكون تحت السهم ^).

- النقر على الأيقونة: يفتح النافذة أو يغلقها. النقر بزر الفأرة الأيمن: قائمة بنمط Windows 11 (فتح / ويدجت / الإعدادات / خروج).
- تمرير المؤشر فوق الأيقونة: "باقي على صلاة <الاسم>: <الوقت المتبقي>".
- الجديد في 1.1.0: أذان بإشعار، كل دول العالم، اسم المدينة والدولة، التقويم الهجري، محول التاريخ، منبه الأذكار، ويدجت أصغر يلتصق بالمواضع، وبطاقة كبيرة عند تمرير المؤشر فوق الأيقونة.
- الإعدادات: المظهر (Mica Alt / Mica / Acrylic - فاتح / غامق) - المدينة - البحث - تحديد الموقع - التوقيت الصيفي - التشغيل مع ويندوز.
- تُحفظ الإعدادات والمواقيت في %APPDATA%\FluentPrayerTimes ليعمل البرنامج دون اتصال بالإنترنت.
- البرنامج غير موقَّع: إذا ظهر SmartScreen فاختر More info ثم Run anyway.
