# 🕌 Fluent Prayer Times
### برنامج مواقيت الصلاة - WinUI 3

مواقيت الصلاة بتصميم Fluent أصيل (WinUI 3): خلفية Mica Alt، وشريط تنقل جانبي، وبطاقات وأزرار اختيار ومفاتيح تبديل بلون تركوازي، مع أيقونة في منطقة الإشعارات وعدّاد تنازلي للصلاة القادمة.

**المطوّر: محمد النجار** · *brought to you by app.instinct AI* · الإصدار 1.1.0

## ✨ المميزات
- أيقونة مئذنة في منطقة الإشعارات: النقر يفتح النافذة أو يغلقها، والنقر بالزر الأيمن يعرض قائمة بنمط Windows 11 (فتح / ويدجت / الإعدادات / خروج)، مع تلميح مباشر بالعدّاد
- عدّاد تنازلي مع تمييز الصلاة القادمة (وبعد العشاء يعرض فجر الغد)
- التاريخ الميلادي والهجري، والأوقات بنظام 12 ساعة
- 31 مدينة مصرية، والبحث عن أي مكان، وإدخال الإحداثيات يدويًا، وتحديد الموقع تلقائيًا
- التوقيت الصيفي: تلقائي / إيقاف (UTC+2) / تشغيل (UTC+3)
- **ويدجت سطح المكتب**: نافذة صغيرة عائمة تعرض الصلاة القادمة والعدّاد، تُحرَّك بالسحب وتُثبَّت فوق النوافذ (من الإعدادات أو بالنقر الأيمن على أيقونة منطقة الإشعارات)
- **الأذان بإشعار**: "حان الآن موعد أذان ..." عند دخول وقت كل صلاة (يمكن إيقافه من الإعدادات)
- **كل دول العالم**: اختيار أي دولة (تُعرض عاصمتها) أو البحث عن أي مدينة في العالم، مع عرض اسم المدينة والدولة في الواجهة الرئيسية، وحساب الأوقات بتوقيت المكان المختار
- **التقويم الهجري**: شهر هجري كامل بأرقام الأيام الميلادية، ونقطة زرقاء سماوية على أيام المناسبات، وقائمة بمناسبات الشهر أسفل التقويم
- **محول التاريخ**: تحويل هجري إلى ميلادي والعكس مع زر لعكس الاتجاه
- **منبه الأذكار**: ذكر عشوائي من حصن المسلم والأذكار اليومية، وتنبيه دوري كل 15 / 30 / 45 / 60 / 120 دقيقة أو مدة مخصصة
- **الويدجت**: أصغر بمقدار النصف، يلتصق تلقائيًا بأقرب موضع (ركن أو منتصف حافة)، ويبقى ظاهرًا عند الضغط على "إظهار سطح المكتب"
- **بطاقة التمرير فوق الأيقونة**: بطاقة كبيرة بخلفية شفافة (Acrylic) وخط واضح بدل التلميح الصغير
- المظهر: Mica Alt / Mica / Acrylic، والسمة فاتحة أو غامقة أو بحسب النظام
- التشغيل مع ويندوز، والعمل دون اتصال بالإنترنت (ذاكرة محلية)، ونسخة واحدة فقط قيد التشغيل
- المواقيت من Aladhan API (طريقة الحساب 5 - الهيئة المصرية العامة للمساحة)

## 📦 المتطلبات
- Windows 10 (1809+) / Windows 11، x64
- **Windows App Runtime 1.6 (x64)** - [التحميل والتثبيت مرة واحدة](https://aka.ms/windowsappsdk/1.6/latest/windowsappruntimeinstall-x64.exe)

## ▶️ التشغيل
نزّل ملف zip من **Releases**، ثم فُكّ الضغط وشغّل `FluentPrayerTimes.exe`. البرنامج غير موقَّع: إذا ظهر SmartScreen فاضغط **More info ثم Run anyway**.

## 🛠️ البناء
يجري البناء على GitHub Actions (`windows-latest`) لأن WinUI 3 يحتاج إلى Windows:

```powershell
dotnet publish FluentPrayerTimes.csproj -c Release -r win-x64 -p:Platform=x64 --self-contained false -o publish
```

## 🚀 إصدار نسخة جديدة
يتولى سير العمل في `.github/workflows/release.yml` البناء، والتحقق من هيكل الناتج، وتجربة تشغيل البرنامج، ثم إنشاء ملف zip ونشر الإصدار.

- **tag:** `git tag v1.1.0 && git push origin v1.1.0`
- **يدويًا:** `Actions` ← `Build and Release` ← `Run workflow` ← أدخل رقم الإصدار

> يُقرأ رقم الإصدار في صفحة "عن البرنامج" تلقائيًا من رقم الوسم (tag).
